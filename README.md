# Social Media Portfolio

This is an instagram-style social media site made as my portfolio.

# Features

+Login and registration
+Mobile and desktop layout
+Homepage with infinite scroll
+Post, like, comment, save, and follow functions
+Backend provided with Supabase

# How to use

Visit the site (https://socmed-supabased.vercel.app/) and register. E-mail verification is not needed.

# Note

The backend uses free Supabase account, which will be automatically paused after a certain period of inactivity. Please contact me if it's paused.
